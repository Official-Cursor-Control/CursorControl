# Seasonal prestige v320

Use `competitive_seasons` and `competitive_awards` rather than resetting permanent progression.

Recommended first season structure:
- 8-12 weeks per season so prestige has time to matter without feeling permanent.
- Permanent all-time PB/rank remains untouched.
- Weekly competition resets create frequent attainable goals.
- Season-end awards are identity cosmetics only: profile badge/frame/title history.

Public profiles should eventually expose a compact `season_history` summary (season key, best placement, badge) but not raw private analytics.
