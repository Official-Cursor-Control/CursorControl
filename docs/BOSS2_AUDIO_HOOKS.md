# Boss 2 optional audio hooks

The fight works without these files. If supplied later, place them in `assets/audio/` with these exact names:

- `serpent_roar_start.mp3` — played once when the Void Serpent fight begins.
- `serpent_attack_1.mp3`
- `serpent_attack_2.mp3`
- `serpent_attack_3.mp3` — randomly selected during serpent attack phases only; never during the meteor intermission.
- `meteor_rumble.mp3` — warning/meteor-wave rumble.
- `meteor_smash.mp3` — cracked purple meteor destruction effect.

Until `meteor_smash.mp3` exists, the existing Survival meteor explosion sound is used as a fallback.
